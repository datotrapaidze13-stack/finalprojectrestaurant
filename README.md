# Step Ordering: ონლაინ რესტორანი

Python/Django-ის საკურსო პროექტი №2.

მომხმარებელს შეუძლია:
1. დაათვალიეროს რესტორნის კერძები
2. გაფილტროს ისინი კატეგორიით, სიცხარით (0-4), ნიგვზის შემცველობითა და ვეგეტარიანულობით
3. დარეგისტრირდეს და შევიდეს საიტზე ელფოსტითა და პაროლით
4. დაამატოს კერძები საკუთარ კალათაში (კალათა მხოლოდ შესულ მომხმარებელს აქვს)
5. კალათაში შეცვალოს რაოდენობა ან წაშალოს კერძი. ჯამურ ფასს საიტი ავტომატურად ითვლის

პროექტის ახსნა: [GUIDE.md](GUIDE.md)

მენიუს მონაცემების წყარო: [API_ახსნა.md](API_ახსნა.md)

## გაშვება

პირველად (ერთხელ):

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py loaddata menu
python manage.py createsuperuser
```

ყოველ ჯერზე:

```bash
.venv\Scripts\activate
python manage.py runserver
```

შემდეგ ბრაუზერში გახსენი:
1. http://127.0.0.1:8000/ : საიტი
2. http://127.0.0.1:8000/admin/ : მართვის პანელი

მართვის პანელში მხოლოდ ადმინისტრატორი შედის, საიტზე რეგისტრირებული ჩვეულებრივი ანგარიში იქ ვერ შევა. ბაზა (`db.sqlite3`) რეპოში არ არის, ამიტომ ყველა თავის კომპიუტერზე საკუთარ ადმინს ქმნის `createsuperuser` ბრძანებით.

ტესტები ამოწმებს, სწორად მუშაობს თუ არა ფილტრები, კალათა და რეგისტრაცია:

```bash
python manage.py test
```
